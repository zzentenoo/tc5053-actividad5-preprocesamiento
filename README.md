# Actividad 5 — Preprocesamiento

Autor: Federico Castro Zenteno.

La libreta resuelve los diez ejercicios, incluye resultados ejecutados, explicaciones en celdas de texto y declaración de uso de IA.

## Cómo revisarla

1. Abrir `Actividad5Preprocesamiento_Federico.ipynb` en Colab o Jupyter.
2. Colocar `heart_disease.csv` en el directorio de trabajo (en Colab, subirlo al entorno).
3. Completar la matrícula y revisar cada explicación y resultado.
4. Usar **Ejecutar todo** y guardar la libreta con las salidas.
5. Subir la libreta y el CSV al repositorio de GitHub. Entregar el enlace directo de la libreta mediante el botón **Entregar tarea** de Canvas.
